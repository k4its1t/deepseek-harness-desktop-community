# DeepSeek Harness Desktop v0.3.2

v0.3.2 修复首次使用时无法从桌面 UI 添加工作区的问题，并给内置诊断 Skill 增加停止预算。

项目继续采用 **Vibe Coding** 方式开发：维护者负责目标、素材与发布决策，**Codex (OpenAI)** 作为开发贡献者参与实现、调试、跨平台设计、测试、打包和文档整理。

## 📁 跨平台工作区浏览器

- “添加工作区”和“选择工作区”现在会打开 Harness 官方应用内目录浏览器。
- 支持目录列表、面包屑导航、直接编辑路径、显示隐藏目录和新建文件夹。
- macOS 与 Windows 使用相同的 browse picker，避免原生选择器外部进程静默失败。
- 选择目录后会登记工作区、创建新会话并立即启用消息输入框。
- Overlay 只影响桌面启动的 Web profile，不改写用户的 `~/.dsh/cordis.patch.yml` 或 profile 配置。

## 🧯 更克制的诊断 Skill

- 单次诊断最多 8 次工具调用。
- 可选证据读取失败一次后停止，不再用不同偏移量重复解析。
- 默认禁止手工拆解 `app.asar`、安装包和可执行文件。
- 失败层已隔离后必须立即报告，把拿不到的实现细节列入 `Unverified`。

## 🧪 验证结果

- 13 项 Node.js 测试通过。
- JavaScript 语法检查通过。
- 3 个 Skill 通过 Harness 原生解析和资源校验。
- macOS arm64 开发版在全新 DSH 数据目录中完成首次添加工作区的真实 UI 回归。
- 工作区注册表正确记录所选目录，新会话输入框正常启用。
- macOS 和 Windows 的打包资源路径均有单元测试覆盖。

Windows x64 采用完全相同的应用内目录浏览器，但最终安装程序和便携版仍需在 Windows GitHub Actions 及实体 Windows 桌面验证。

**English summary:** v0.3.2 fixes the non-responsive Add/Select Workspace flow by pinning the official in-app browse picker for both macOS and Windows. It also adds hard tool-call and retry limits to the bundled diagnostic Skill. The release was produced through a Vibe Coding workflow with Codex credited as a development contributor.
