# DeepSeek Harness Desktop v0.4.0

## 🛠️ 内核升级，旧数据先备份

- 内置 Harness CLI 和 DSH 子包统一固定至 **0.1.5-rc.1**，同步依赖锁文件与第三方许可清单。
- 升级前提醒关闭其他 Harness 实例，并备份已有配置、凭据、会话和自定义内容。备份失败就暂停，支持重试；恢复方式见[升级指南](../UPGRADING.md)。
- 适配新版启动认证与参数顺序，客户端启动不再额外打开浏览器；诊断日志也不会记录启动认证 URL。
- 增加错误恢复页、重试和打开日志入口；“关于”显示桌面与内核版本。
- 纳入外观、缩放、窗口尺寸记忆和默认关闭的详细运行日志。Windows 退出时清理所属进程树。
- 下载附件继续使用固定名称，历史发布页与更新日志保留。旧书签继续可用 (￣▽￣)b。

## English

This release bundles Harness **0.1.5-rc.1**, adds private pre-upgrade backups and startup recovery, and includes persistent desktop preferences. The official Web UI stays inside the desktop window; startup authentication URLs are omitted from diagnostics. Runtime and desktop versions appear in About.

Close other Harness instances before upgrading. Backups contain credentials: keep them private. Restore the complete backup before running an older runtime against existing data. New users still configure their own API credentials.

## Validation and limits

Acceptance covers isolated startup, workspace selection with Chinese and space-containing paths, a local mock model, real shell tools, cancellation, app restart, recovery-page retry, old Web-session migration, and restoring a backup through the old persistence implementation. Platform builds must pass their acceptance jobs before publication; macOS packages must also pass strict signature verification.

Windows CI installs the NSIS package and runs automated checks. Manual Windows focus behavior, SmartScreen and installer interactions remain unverified. Without configured certificates, macOS packages use ad-hoc signatures, not Developer ID notarization; Windows packages are not commercially signed.

This is an **unofficial community project**, developed through **Vibe Coding**, with **Codex (OpenAI)** as a contributor. Feedback, reproducible bug reports, forks and your own adaptations are welcome.
