# DeepSeek Harness Desktop v0.3.0

> 🐋 大肥鱼 icon 正式上岗！这次把桌面壳、3 个 Skill 和新视觉一次整理到位。胖得很稳，功能也不含糊 (≧▽≦)

DeepSeek Harness Desktop 是面向 macOS 与 Windows 的非官方开源桌面包装。它在原生 Electron 窗口中运行 DeepSeek Harness Web UI 与 Agent 运行时，自动复用现有 `~/.dsh` 数据，普通用户无需另装 Node.js 或 `dsh`。

## 🎨 新版“大肥鱼”图标

- 换用维护者确认的“大肥鱼”角色版应用图标。
- 提供 1024×1024 PNG，供窗口和启动页显示。
- 生成多分辨率 macOS ICNS，写入 `.app` 应用包。
- 生成 Windows ICO，供 NSIS 安装程序、可执行文件与系统快捷方式使用。
- macOS、Windows、运行窗口和加载界面统一使用同一套视觉资源。
- 移除旧紫色占位图标和未采用的黑鲸候选，只保留当前正式图标。
- 软件显示名称统一为 **DeepSeek Harness Desktop**。

## 🧩 配套 Skills

### `/diagnose-harness-desktop`

- 随客户端内置。
- 以只读方式检查桌面启动、Web UI、API、会话、Profile、工具、权限与打包问题。
- 优先收集可验证证据，不靠“玄学重启”硬猜。

### `/prepare-harness-bug-report`

- 随客户端内置。
- 把诊断证据脱敏整理成结构清楚、可复现的 GitHub Issue 草稿。
- 只生成草稿；未经明确许可，不会替用户提交 Issue。

### `/analyze-images-locally`

- 可独立安装。
- 将本地截图、照片、扫描文档、图表或流程图交给用户已安装的 Ollama 视觉模型观察。
- 把视觉结果整理成结构化证据，再交给当前纯文本 DeepSeek 模型继续推理。
- 本机只有 Tesseract 时可以降级为纯 OCR。
- 不会擅自安装或下载多 GB 视觉模型，也不使用云端视觉服务兜底。相当于给纯文本模型配了一副本地眼镜 ( •̀ ω •́ )✧。

### Skill 安全与验证

- 安装版通过 `DSH_BUNDLED_SKILL_DIR` 自动加载两个内置 Skill。
- 提供包含全部 3 个 Skill 的独立 ZIP，方便安装到其他 Harness 环境。
- Skill 默认不读取或输出 API 密钥。
- 未经用户明确同意，不发送测试请求、不修改配置、不提交 GitHub Issue。
- `npm test` 使用锁定版本的 Harness 解析器检查 Skill 发现、元数据、调用策略和资源文件。

## 🖥️ 桌面能力

- 使用固定版本 `@deepseek-ai/dsh` 和完整生产依赖运行官方 Harness Web UI。
- 自动复用现有 `~/.dsh` API 设置、会话、Profile 和工具配置。
- 运行时仅绑定随机 `127.0.0.1` 回环端口，不对局域网开放。
- Electron Renderer 使用 Chromium sandbox、`contextIsolation`，并关闭 Node integration。
- 限制导航、新窗口和高权限桥接，外部网页交给系统浏览器。
- 应用退出时自动清理 Harness 子进程。
